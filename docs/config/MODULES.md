# Modules

## Currently implemented modules

| Name              | Type      | Format                                   |
| ----------------- | --------- | ---------------------------------------- |
| Operating System  | os        | {PRETTY_NAME(1)}{VERSION_ID(2)}{Arch(3)} |
| Kernel            | kernel    | {kernel(1)}                              |
| User and Hostname | userhost  | {user(1)}{hostname(1)}                   |
| Shell             | shell     | {shell_path(1)}                          |
| Separator         | separator | {separator_character(1)}                 |

NOTE: At the moment theres no format for custom modules
